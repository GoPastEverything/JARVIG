# Parametric geometry

ADR: [ADR-0062](../adr/ADR-0062-parametric-geometry-is-the-object.md). World replacement: [ADR-0063](../adr/ADR-0063-render-residency-does-not-outlive-the-world.md). Derived clusters: [ADR-0064](../adr/ADR-0064-a-parametric-solid-builds-its-clusters.md). Exact solids: [ADR-0065](../adr/ADR-0065-an-exact-parametric-solid-draws-no-relief.md). Parameters and capabilities: [ADR-0066](../adr/ADR-0066-a-solid-keeps-its-parameters.md). Operation session: [ADR-0067](../adr/ADR-0067-a-modeling-operation-is-one-session.md). Direct manipulation and topology: [ADR-0069](../adr/ADR-0069-direct-manipulation-commits-and-topology-is-the-solid.md).

A Block is the object. Meshlets, cluster hierarchy, visibility, level of detail, and Einstein detail are derived representations. Einstein is surface discretization. It is not the definition of existence, the collision solid, the transform, or the coordinate system.

```text
Parametric solid
  -> canonical surface
  -> derived mesh
  -> meshlets, hierarchy, visibility, LOD
  -> Einstein detail when the existing policy asks for it
  -> GPU
```

The saved component is `ParametricBlock`. The level writes format version 6 only when a block is present. The file stores full extents in meters, one material slot, and the entity transform. A solid that is not plain also stores per-face inset, one bevel, and a history log. It does not store triangles, meshlets, or Einstein patches. The runtime mesh is rebuilt from that record. Object scale stays (1, 1, 1). Size is not a frame scale.

Collision is the analytic oriented box in the entity frame: half extents are `size / 2`. Play's free-fly pawn is kept outside that box by a small radius. There is no physics solver. This is not JRV-0090.

An Empty level is World Settings only. File > New Level confirms that, then writes the existing empty document. Replacing the world releases that world's render residency before the next frame: mesh buffers, meshlet records, hierarchy, parent geometry, meshlet debug, and Einstein patches. `MeshId` starts again at 1, so those objects must not survive. The device, the editor grid, and the project asset library stay. Asset meshlets are not attached to the new world's runtime mesh ids. ADR-0063. The ground grid and the axis triad are editor reference on the existing frame (+X right, +Y up, −Z forward, meters). They are not entities, they are not saved, and they do not draw in Play. Create > Block places the first solid at scene-local (0, 1, −4) with size (2, 2, 2) m. Later blocks step 2.5 m on +X. The derived mesh is uploaded from the block's size. The same generation calls the existing meshlet builder. On a 2 m cube the minimum 8-cell grid splits each face's two triangles, so the measured set is 12 meshlets of one triangle, with missing and duplicate coverage both zero. Those clusters are world residency. They are not a `.jarvigmeshlets` sidecar and they are not in the level. An imported mesh with no usable sidecar still has zero candidates. ADR-0064.

The evaluated analytic solid is the size, six face insets, and one bevel. Faces are +X, −X, +Y, −Y, +Z, −Z. A plain record has zero insets, zero bevel, an empty history, and no body, and the level still writes only the size and the material. Any other analytic record also writes `inset_m`, `bevel_m`, and `history` in the same component version and the same format 6. The first committed topology edit also writes `body`: vertices, edges, and faces with durable ids. That key is omitted when the body is absent. The component version and the type-registry version are unchanged. History keeps the last 24 edits and drops the oldest. The mesh is rebuilt from the stored body when one exists, and from the stored numbers otherwise. It is not rebuilt by replaying the log, and an entry cannot be muted. A face push on an analytic box grows one axis and moves the center by half the change, so the opposite face stays. An inspector size edit keeps the center. On a stored body the same size edit scales the vertices about the center and keeps the ids. Bevel and inset clamp to 45% of the shortest side and stay inside the analytic box. A topology edit recenters the body so its bounds center stays at the local origin, sets `size_m` to that bounds size, and shifts the entity translation once by the same amount. Collision is still that box of `size`, so a slanted face stays inside the box and the collider does not shrink to the chamfer. A canonical box body is 12 triangles. Move Edge stays at 12. Split Edge is 14. Extrude Edge is 16. Subdivide Face at 2 by 2 is 22. A featured surface is not the plain 12-triangle audit. It uses the same meshlet builder, and an authored block stays Exact. ADR-0066. ADR-0069.

The inspector asks what the selected entity can do. A block advertises Transformable, ParametricSolid, FaceEditable, Patternable, MaterialAssignable, Collidable, and ComponentHost. BooleanOperand is named and stays false until a boolean exists. Select, Transform, Dimensions, Model, Geometry, and History are those capabilities. Pattern and Placement are not section titles. The registry group is still Shape. The size section is still Dimensions. Select is one row: Auto, Object, Face, Edge, and Vert. Model is a two-column icon shelf and it follows the mode. Face mode shows Extrude, Inset, Bevel, Subdivide, and 4×4. Edge mode shows Move Edge, Extrude Edge, and Split Edge. Vertex mode shows Move. Object mode shows Bevel, Reset Shape, Duplicate, Mirror, Align, and Snap. An open operation replaces that shelf with an Active Tool card: the amount when the operation has one, Cancel, and Done. Geometry lists faces, edges, vertices, and closed. Show Grid sits there when the body is stored, and it is the same toggle as View > Show Grid. History is the current size, any nonzero bevel or inset, and the latest log lines, newest first. An imported mesh can take a material and does not get the solid tools. A light, a camera, and a player spawn do not either. Duplicate is the existing duplicate command. Mirror of a stored body flips the axis and reverses each face loop so the outward orientation survives. Align drops the lowest corner onto scene Y = 0. Snap rounds local translation to 0.1 m and does not change the Move gizmo. See [../editor/gizmos.md](../editor/gizmos.md).

Extrude, Inset, and Bevel are one session. The toolbar icon, the Amount field, and one viewport arrow share that amount. A drag snaps its delta to 0.05 m. A typed amount is exact. Preview does not append history until the gesture ends. Mouse-up of a viewport drag commits that preview, writes one log line, and closes the session. Done remains for a typed amount that was not dragged. Cancel, Escape, and a right-click during the drag restore the solid from when the drag began and push no undo entry. Choosing Move or Rotate cancels the session. A resize during the drag restores the baseline and leaves the session open. The permanent Bevel field, the six Inset fields, and the raw history string are not on the panel. History lists the current size, any nonzero bevel or inset, and the latest edits as read-only lines. Clicking a bevel or inset row reopens that current amount. A log line does not. That list is the current parameters plus a log. It is not a stack that can mute a step and rebuild. Move Edge, Extrude Edge, and Move Vertex are the same kind of session, with no Amount field. The toolbar shows them as Edge, Extend, and Vertex, next to Subdiv and Split, while a solid is selected. The translate gizmo sits on the selected edge or vertex. Dragging an axis edits that element. A press that misses the gizmo drags on the view plane. Mouse-up commits. Split Edge and Subdivide Face commit on the click. A topology edit is refused while a bevel or an inset is still set. Once a body is stored, Inset and Bevel on that solid are refused. Extrude moves the selected faces along their shared outward direction, keeps those face ids on the caps, and adds the side faces. Adjacent faces that still meet share one edge and its vertices. A sweep that stays on the neighbor trims that neighbor instead of stacking a second polygon. A result that would open the solid is refused. Subdivide writes those faces into the body. A rectangle whose boundary already carries split vertices is still a quad: the grid keeps those vertices and uses enough divisions to land on them. A selected edge or vertex subdivides a rectangular face of that element. No element selected still uses +X, and the editor says so. From Edge, Vertex, or Object the editor switches to Face and selects the cell, so the next click can choose another piece. Einstein does not write those faces. ADR-0067. ADR-0069. ADR-0070.

A single click selects the current element. A double-click promotes to the object. Auto, Object, Face, Edge, and Vertex are the modes, and only on a parametric solid. Auto still selects a face. An edge and a vertex carry durable ids on the authored body. Those ids are not triangle or meshlet indices, and they survive a later split, subdivision, scale, and mirror. Select mode drags a marquee on empty space: left to right takes objects fully inside the rectangle, and right to left takes objects the rectangle touches. The whole object outlines its analytic box. View > Show Grid draws the stored edges in Object mode as well. Face mode, and Auto once a body is stored, draw those edges without the toggle. Each line is one editable edge, and each enclosed region is one editable face. A face outlines that face. Shift-click adds faces on the same solid. Ctrl-click toggles one. A selected edge is drawn thick. A vertex is a point. Editor undo is a separate stack of 64 transactions. One drag, one sculpt stroke, and one numeric field are each one entry. A committed modeling drag is one of those entries. The feature log stays the log. ADR-0068. ADR-0069.

Boolean union, subtract, and intersect stay later. Sketch, then extrude from that sketch, revolve, sweep, and loft, come after booleans. Cylinders, ramps, spheres, and chart-based Einstein detail on curved solids are later. A Graybox level will be an ordinary level file: World Settings, a light, the environment, a Player Start, and a floor Block. It does not need a special engine type.

`PROCEDURAL_MICROGEOMETRY_DEFAULT` stays false. RFC-0002 stays unstamped. The block stays in the same classifier. Auto still treats it as an opaque solid. A visible cluster of an exact solid is `Exact`, including when the 2 cm feature projects past 1 px, and no patch is built. Off-screen and occluded clusters keep those reasons. The surface builder is unchanged. Exact solids are not submitted to it. The private surface rule is not in this repository. Einstein surface builds run on a sibling `JobManager` with one worker, `jarvig-einstein-0`. Parent-mesh LOD, registry scans, and terrain chunks stay on the general pool. ADR-0071. Imported meshes, including flat walls, still use the 1 px gate. ADR-0065. Micro Off and Auto draw the same mesh. While the solid is plain, that mesh is the 12-triangle box. Changing the size while inset and bevel stay zero preserves eight corners, six planar faces, twelve triangles, consistent winding, coincident boundaries, exact meshlet coverage, and parent spheres that contain their children. Debug views remain visualizations. When the coverage work is finished, ordinary derived meshes are supposed to enter the same geometry system without a user-facing experimental switch.
