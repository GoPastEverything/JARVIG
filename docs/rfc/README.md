# Requests for comments

RFCs propose substantial systems that are not accepted architecture. An accepted ADR promotes a result. An RFC does not.

Every RFC needs a hypothesis, a baseline, a feature flag, test scenes, metrics, expected failures, and a promotion threshold. Research that cannot fail is not an RFC.

Status values: Proposed, Accepted, Rejected, Superseded. RFC-0001 is Accepted for the hierarchy architecture. That acceptance does not turn `virtualGeometry` on by default and does not close its performance follow-ups. The milestones in `ROADMAP.md` still name the work. They do not turn the flags on.
