ADR-0074 — Intent authority for eligible solids

Status: Proposed Date: 2026-10-05

Context

ADR-0073 says the evaluated body is the solid. When BlockRecord.body is present, that body is the geometry. When it is absent, the solid is the size, the six insets, and the one bevel. Replaying history or steps is not a way to obtain it. The editor log keeps 24 entries. Derived mesh, meshlets, hierarchy, Einstein patches, and GPU buffers are disposable products of that record.

RFC-0007, still Proposed, built a second tape, intent. That tape is uncapped, starts at creation for a newly authored solid, and stores semantic identity rather than evaluated topology. The Intent Authority Candidate can rebuild a complete tape after the body is removed. The eligibility gate is stricter than completeness. It names every reason a solid is not yet safe to treat as self-describing.

A later per-camera realization needs one geometric truth. This record is the proposed rule for that truth. It is not the activation of the rule, and it does not start per-camera synthesis.

Decision

This ADR is Proposed. It is not accepted. ADR-0073 remains the rule for every file that stores a body, and for every ineligible record. The 2026-10-05 load preflight added one experimental exception in spawn_saved_block: when the file has no body and the tape is eligible, spawn installs the reconstructed body before the mesh, the meshlets, and collision are built. On 2026-10-06 Experiment 1 gated that call with SceneWorld.intent_authority_experiment. The flag defaults to off, is not a level field, and is not serialized. instantiate passes false. instantiate_with_experiment sets the flag before the spawn loop. The preflight tests opt in. parse_level does not reconstruct. A divergent stored body is kept. The renderer, Einstein, microgeometry, and the hierarchy code are unchanged. No legacy file is migrated. Format 6, component version 1, and type registry 9 stay. Experiment 1B, the same day, adds discard_live_block_realization and rerealize_live_block_from_intent. Both refuse when the switch is off and when the solid is ineligible, including a divergent stored body. The candidate is given a copy whose body is None. Neither call reloads the level or rereads a file. That run does not accept this ADR. Experiment 2, the same day, is a default-off measurement of two disposable meshes generated from that body for 0.5 px and 4.0 px. The shared derived mesh stays the control. That run is frozen as PASS-DIAGNOSTIC and does not accept this ADR. Experiment 2B, the same day, presented those two meshes in one frame on two live views. That run does not accept this ADR. Experiment 3 was designed on 2026-10-06. Experiment 3A is frozen as PASS and does not accept this ADR. Experiment 3B, the same day, uploaded those admitted-only products as two color-pass meshes and passed on Intel UHD. Face 89 was 0 GPU bytes in observation A and 558 GPU bytes in observation B. That run does not accept this ADR. Experiment 3C, observation-conditioned direct realization, was implemented on 2026-10-06. The Intel UHD editor run stopped before any direct product was uploaded, because the eligible Intent Solid has no evaluated body unless this ADR's experiment switch is on, and the 3C launch refuses that switch. That result does not accept this ADR. A later run the same day kept the switch off, used the analytic specimen as its own authority, presented 0, 72, and 392 triangles in one Intel UHD frame, and does not accept this ADR. Experiment 3C is frozen as PASS. Experiment 4 is designed on 2026-10-06 and is not implemented. That design does not accept this ADR. On 2026-10-06 the same experiment passed on Intel UHD. The eligible tape plus an experiment-local curved trailer drove two observations, a Size edit changed the authority hash from fbdd144e5cd4b21f to d5f4177dcd12550c, and the previous GPU meshes were rejected. The curved trailer stayed outside the production intent schema. That pass does not accept this ADR. Experiment 5, Persistent Analytic Intent, is designed on 2026-10-06 and is not implemented. One saved analytic chart would not accept this ADR.

The rule this record proposes, and does not activate:

For an object that reports INTENT_AUTHORITY_ELIGIBLE only, the persistent geometric intent becomes authoritative and the evaluated body becomes a disposable realization. Legacy concrete-only objects and incomplete objects continue to use the stored-body contract in ADR-0073.

Eligibility is the gate already implemented. Eligible requires every one of these. Anything else is Ineligible with one named blocker per reason.

  • The semantic record begins at object creation, including seed_size_m.
  • No geometry-changing operation is uncaptured. A gap names the operation and its 1-based index on the persistent intent tape. The stored word is hyphenated, so the uniform bevel is uniform-bevel. An empty tape has no intent index: those step numbers are indices on the retained history, and the first blocker is legacy concrete-only history has no semantic program.
  • Every semantic reference resolves to one concrete element. Two matches and a reference the new topology does not contain are refusals. There is no fallback to a stored face, edge, or vertex id.
  • The evaluated body can be deleted. Derived mesh, meshlets, hierarchy, Einstein patches, render caches, and topology caches can be deleted with it. Exact solids build no Einstein patches.
  • Cold reconstruction from the intent tape alone produces a valid closed body. intent_authority_candidate does not read record.body. A stored body is compared only after that reconstruction. Positions agree within 1e-6 m, bounds within 1e-6 m, and volume within 1e-8 m³, or the topology compares equal.
  • The reconstructed body can take further scene edits. Those edits append to the same tape. A second total discard and reconstruction matches.
  • Save and reload preserve the tape. The material validates and stays on the record. Entity name and translation are not geometric operations and survive with the entity.
  • A size-only box does not open a tape. A concrete-only log does not open a partial tape on a later edit. Both are ineligible.

The diagnostic line is Intent Authority: ELIGIBLE, or one line per blocker: Intent Authority: INELIGIBLE — {reason}. Example: Intent Authority: INELIGIBLE — uncaptured operation: uniform-bevel step 1. View > Geometry Truth > Intent Shadow prints the line and does not install a body.

The command audit, and the torture that passed on 2026-10-05, are in RFC-0007. That RFC stays Proposed.

Load preflight

The preflight passed on 2026-10-05. It is recorded in RFC-0007. An eligible chain longer than 64 intent entries was saved without its body. instantiate realized that body. The spawned solid matched the control that had been saved with the body: topology, semantic provenance, material, mesh, meshlets, cluster hierarchy, exact Einstein classification, and collision. A further scene-command split and size edit saved, reloaded, and survived a second strip and realization. A stored body moved by 5e-4 m was kept. A plain cube, a uniform bevel, an inset, and a legacy stored body stayed on the ADR-0073 path. An eligible analytic face push, which never stored a body, realized a closed box on spawn. create_block of that same record does not. That 2026-10-05 call was class-wide. On 2026-10-06 it is gated by the default-off switch, and those tests opt in. Default instantiate of an eligible body-less file leaves the body absent.

What remains before this ADR can be accepted

The preflight makes one sentence ready for a human decision. An eligible file with no evaluated body loads as the realization of its tape, and every other file keeps the stored-body contract. Accepting this record is that decision. These items are still open.

  • A human has to accept this ADR. Proposed is not architecture. This preflight does not accept it.
  • A file that still contains a body keeps that body, even when the body diverges from the tape. The full sentence "intent wins over a stored body" is a later change. This preflight did not make it.
  • An eligible analytic face push now materializes a body on spawn. Collision still reads the size and the pose. The mesh becomes mesh_from_body. That consequence needs to be part of the acceptance.
  • block_mesh, collision, and the renderer read the body or the mesh spawn installed. They were not switched onto a replay of their own. A GPU frame of the 2026-10-05 class-wide preflight was not presented. On 2026-10-06 Experiment 1 showed Intel UHD frames of one opted-in solid: the reconstructed cage with the switch on, the analytic size box with the switch off, and the edited solid after a scene-command split and a size edit. The shelf extrude and split were not clicked. Experiment 1B then discarded that live solid's body, mesh, meshlets, and hierarchy and rebuilt them in the same process. The CPU test has no swapchain, so its frame line is NOT PRESENTED. The editor, with --intent-authority-experiment and --intent-live-rerealize, presented the regenerated solid on Intel UHD, split one named edge, rebuilt again, and printed PRESENTED, Post-regeneration edit: VALID, and Legacy object: UNCHANGED. The live flag alone does not turn the switch on. Those frames do not accept this ADR.
  • Product capture, with the switch off, still writes the evaluated body. With the experiment on, LevelDocument::capture omits an eligible body and keeps a legacy body. capture_entity still keeps the body, and editor undo restores that memento. Undo does not rebuild the solid by replaying intent. The undo stack is capped at 64 full-record mementos. The intent tape inside a surviving record is not capped. A File > Save of the experiment level on 2026-10-06 stayed format 6, omitted the eligible body, and kept the legacy body.
  • These operations have no safe reconstruction and stay ineligible: analytic inset, uniform bevel, mirror of a solid that has no body, a vertex move with no provenance, a face extrude after a body exists, Reset Shape (the result is a new legacy 2 m cube and the material is kept), and a preview or restore that leaves a body the tape did not produce.
  • A pre-tape concrete log stays unrecorded. A later in-scope edit on that log does not open a partial tape.
  • The 24-entry editor log still drops its prefix. Phase 1 still reports that drop. That log must not become the geometric authority. The uncapped tape is the semantic record.
  • Bevel still refuses the concave carved lip. The refusal stores nothing.
  • Experiment 2 measured disposable per-view meshes on 2026-10-06 behind --view-realization-experiment. The default renderer stayed the shared mesh and its cluster cuts. That measurement is frozen as PASS-DIAGNOSTIC. Experiment 2B presented both meshes at once and still does not accept this ADR. Accepting this ADR would not authorize product per-camera synthesis. That remains a later decision, after eligible intent is the truth and the evaluated body is only a realization.
  • No format migration is included. Level format 6, component version 1, and type registry 9 stay.
  • Experiment 5, on 2026-10-06, stored one analytic chart as intent and did not accept this ADR. The outer level format stayed 6 and the type registry stayed 9. The ParametricBlock component schema moved to version 2 only for a tape that contains analytic-surface. A planar tape stays version 1. That component bump is the persistence boundary for the new intent word. It is not a format migration for this ADR, and it does not make an analytic chart an eligible boundary-representation operand. The analytic proof stayed Intent Authority: INELIGIBLE.
  • Experiment 6, persisted authoring intent, is designed on 2026-10-06 and is not implemented. It asks whether the existing eligible modeling tape, already saved without a body, can survive a written Size edit and drive two observation meshes from the reloaded tape. It does not accept this ADR. It does not enable the experiment switch, does not omit a stored body, and does not start per-camera synthesis as the renderer. A planar fan has no resolution ladder, so the design does not require n_close > n_far.
  • On 2026-10-06 Experiment 6 ran behind --authored-intent-6 and failed. The first Intel UHD frame presented two different fans from the 65-entry tape. The saved Size append left stored size at Y 2.5 while reconstruction became Y 2.6, so the reloaded tape was ineligible. The gate was not widened. The second present was not run. That result does not accept this ADR.
  • The duplicate-authority design of 2026-10-06 names size_m on an eligible body-less record as the replay AABB cache, written by the authoring transaction and checked by the existing eligibility comparison. Parse does not regenerate it. A stored body and every ineligible record stay on ADR-0073. This design does not accept this ADR, does not amend ADR-0073, and adds no format migration.
  • On 2026-10-06 that writer rule was implemented as commit_class_c_intent. An eligible body-less transaction writes size_m from the replay AABB. Replay starts at seed_size_m and does not read size_m. Parse still does not repair a stale cache. The cache-contract test passed, and a separate --authored-intent-6 rerun on a new project passed on Intel UHD. The original Experiment 6 FAIL stays. This bullet does not accept this ADR, does not amend ADR-0073, and adds no format migration.
  • The Experiment 6 rerun is frozen as PASS on 2026-10-06. That stamp does not accept this ADR. Experiment 7, one persisted round on the same kind of body-less tape, is designed and is not implemented. analytic-surface stays refused as a boundary-representation operand, a bevel stays a planar chamfer, and a real round would require an eligibility-contract change that was not made. The gate was not modified. This bullet does not accept this ADR.
  • On 2026-10-06 Experiment 7 was implemented behind --authored-curve-7 and passed on Intel UHD. ParametricBlock version 3 stores one round that names a persistent semantic edge token. The planar 1e-6 comparison was not widened. analytic-surface stays refused. A bevel stays a planar chamfer. Level format 6 and type registry 9 stay. The saved specimen is eligible, the body is absent, and the ordinary renderer stayed the control. This bullet does not accept this ADR, does not amend ADR-0073, and adds no format migration.
  • On 2026-10-06 a later corner sequence drew that same round at fixed presentation distances: a sharp corner, a 0.050 m fillet at 6 far and 11 close divisions, a wireframe of those rulings, a reload, and a 0.040 m edit at 5 far and 10 close. The user orbited the reloaded 0.040 m fillet and sent two frames of it. The mesh in those frames is the close observation kept after the split was released. This bullet does not accept this ADR, does not amend ADR-0073, and adds no format migration.
  • The full suite, pnpm build, and pnpm smoke were not run for this draft. The Intent Shadow window was not opened. Experiment 1, Experiment 1B, Experiment 2, and Experiment 2B presented GPU frames on 2026-10-06. Those frames are not an acceptance.
  • The five native failures recorded before ADR-0073 remain. They are not part of this decision.

Alternatives Considered

  • Accept this rule in the same change as the gate. Rejected for this slice. The gate is evidence. ADR-0073 still names the stored body as the solid, and a Proposed ADR does not override an Accepted one.
  • Make every complete tape authoritative, including a solid that still carries an inset or a uniform bevel. Rejected. Those parameters change the mesh and are not a replayable SolidBody. The gate refuses them by name.
  • Fall back to the concrete id when a semantic reference misses. Rejected. Concrete ids change after an upstream edit. A miss or a double match is a refusal.
  • Migrate legacy files onto a synthesized tape. Rejected. A concrete-only log has no recorded provenance. Inventing F:seed names for it would hide a second definition of the object.
  • Start per-camera synthesis for eligible objects now. Rejected. One truth has to be accepted before two cameras are allowed to realize it differently. The 2026-10-06 measurements, including Experiment 2B's two live views, are a default-off experiment beside the control renderer. They are not this alternative.

Consequences

With the experiment switch on, spawn of an eligible file that omits the body installs a realization, and an already-spawned eligible solid can discard that realization and install a new one from the tape. Spawn of any other block installs the record the file stored. Default spawn does not realize. With the switch off, the live discard and the live rebuild refuse and write nothing. The renderer, Einstein, microgeometry, the meshlet builder, and the hierarchy builder were not edited. They read the body or the mesh that spawn installed. A later product save, with the switch off, writes the realized body. A save while the experiment flag is on omits an eligible body. Stripping that body and loading again with the switch on realizes it again. Accepting this ADR would record that behavior as the rule. This file does not perform that acceptance, and it does not make a stored body lose to the tape. A per-view realization from Experiment 2 or Experiment 2B is not stored, is not the object mesh, and is not this acceptance.

Supersedes

Nothing. This record is Proposed. It does not supersede ADR-0073. ADR-0066 still rejects replay as the source of truth until a later accepted ADR says otherwise.
