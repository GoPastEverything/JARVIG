JARVIG documentation

designdoc.html at the repository root is the founding specification. These pages are the maintainable form of that document. They do not replace it.

The creator manual is manual/README.md. The rendered site is site/index.html. Rebuild it with pwsh -File scripts\build-docs.ps1. That site is a reader. It is not a second authority.
